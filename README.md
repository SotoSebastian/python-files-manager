# Gestor de archivos locales

Organizador automático de archivos en Python.

Clasifica archivos según su extensión y los mueve a carpetas específicas como imágenes, videos y documentos.

## Características

- Detecta extensiones automáticamente
- Crea carpetas si no existen
- Organiza imágenes, videos y documentos
- Fácil de ampliar con nuevas categorías
